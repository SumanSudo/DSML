# Object-Oriented Programming (OOP)

## What is OOP?

Object-Oriented Programming (OOP) is a programming paradigm that uses **classes** and **objects** to organize and manage code efficiently.

---

## Class

A **class** is a blueprint or template used to create objects.

---

## Object

An **object** is an instance of a class. Each object has its own data and behavior.

---

## Attribute

An **attribute** is a variable that stores data related to an object.

---

## Method

A **method** is a function defined inside a class that describes the behavior of an object.

---

## Constructor (`__init__`)

A **constructor** is a special method that is automatically called when an object is created. It is used to initialize object attributes.

---

## `self`

- Refers to the current object.
- Used to access instance attributes and methods.
- Must be the first parameter of every instance method.

---

# Four Pillars of OOP

## 1. Encapsulation

Wrapping data and methods into a single unit (class) while controlling access to the data.

## 2. Abstraction

Hiding implementation details and exposing only the necessary functionality.

## 3. Inheritance

Creating a new class from an existing class to reuse and extend its features.

## 4. Polymorphism

Allowing the same method or interface to behave differently for different objects.

---

# Advantages of OOP

- Code Reusability
- Better Code Organization
- Easier Maintenance
- Improved Scalability
- Real-World Modeling
